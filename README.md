# Калькулятор промывки отопления — PWA

## Публикация через GitHub Pages
1. В GitHub создайте новый **публичный** репозиторий, например `promyvka-calculator`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `manifest.webmanifest`, `service-worker.js` и папку `icons`.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку `main`, папку `/ (root)` и нажмите Save.
5. Дождитесь публикации. Ссылка будет вида `https://ВАШ-ЛОГИН.github.io/promyvka-calculator/`.
6. Откройте ссылку на Android в Chrome → меню ⋮ → «Установить приложение» (либо «Добавить на главный экран»).

## Важно
- Приложение и тестовые расценки общедоступны по ссылке. Не публикуйте реальные секреты или конфиденциальные данные в HTML/JS.
- История и прайс сохраняются локально в браузере на **каждом устройстве отдельно**. Автоматической синхронизации нет.
- Данные старого локального HTML-файла **не переносятся автоматически** на опубликованный сайт.
- На странице «История» можно экспортировать резервную копию JSON; импорт пока не реализован.
- После первого успешного открытия по HTTPS приложение может работать без интернета. Проверьте автономную работу на своём телефоне.
- При следующем обновлении измените имя CACHE в `service-worker.js` (например, на `promyvka-pwa-v2`) и перезагрузите приложение с подключённым интернетом.
